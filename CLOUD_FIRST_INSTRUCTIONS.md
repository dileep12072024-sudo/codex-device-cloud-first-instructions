# Cloud-first instructions for this device

At the start of every task, read and follow this file, regardless of which Codex account is signed in.

## Execution and storage

- Use a cloud server for task execution by default. Choose Kaggle, Google Colab, or GitHub Codespaces based on the task’s needs and the quality required. Use another suitable cloud service when those are a poor fit.
- Create a dedicated GitHub repository for task files and keep working files there instead of accumulating them on this device.
- Prefer private repositories when they contain personal or unpublished material.
- Do not execute locally or leave task files on this device when the required cloud service is not connected. Tell the user what authorization or connection is needed, then continue in the cloud after it is available.
- Use local execution only if the user explicitly asks for it or authorizes it for that task.

## Session setup

- If a cloud service or GitHub account is not connected, identify the exact MCP or authorization link needed and ask the user to connect it.
- After connection, verify access before uploading files or starting execution.
- Clean up temporary local files created during setup when they are no longer needed.

This file is a device-local instruction source. It applies to any Codex account that is explicitly told to read and follow this path; it does not automatically change account-level settings.
